# 路由与近邻 Skill 交接

## 唯一主触发条件

只有同时满足以下两项时，本 Skill 才主导任务：

1. 请求有明确的最新海外隔夜锚点：美国或全球市场的事件、财报、监管变化、产业信号、个股/板块/ETF异常价格行为，或用户明确要求扫描“昨夜/隔夜”。
2. 用户要把该锚点映射到A股产业环节、公司、预期差或盘前候选池。

只有“A股”“盘前”“股票池”“产业链”“公司验证”等词，不足以触发。

## 近邻边界

### a-stock-trading-review

它拥有：A股全市场环境、赚钱效应、板块生命周期、持仓相对强弱、个人交易复盘、次日综合预案和盘前轻量更新。

本 Skill 不拥有这些任务。若请求是“复盘今天A股”“看看我的持仓”“明日核心池”，且没有海外隔夜锚点，直接交给它。

复合请求示例：“结合昨夜英伟达财报和今天A股全市场，做明日预案”。先由本 Skill 生成海外催化映射模块，再由 `a-stock-trading-review` 把该模块放入全市场与持仓框架；不得由本 Skill越权完成全市场九步复盘。

### a-stock-evidence-research

它拥有：单一A股消息真假、客户/订单/技术/产能、业务真实性、传闻与事实的专项核验。

本 Skill 只在海外催化映射链中对 Candidate 做初筛，并对 Shortlist 按10步法验证。若用户主要问“某公司是否真的供货”“订单传闻真假”，且不要求从昨夜海外事件建立映射，交给 `a-stock-evidence-research`。

复合请求中，本 Skill 可提出待核验主张；需要专项深挖时交给证据研究 Skill，并把结果作为 Evidence 输入，不重复声称已验证。

### a-stock-investment-analysis

它拥有：完整公司质量、财务诊断、盈利预测、估值、情景分析、行业地位和完整深度报告。

本 Skill 只判断海外催化的传导、业绩/管线成熟度和盘前静态交易状态。若用户主要问长期投资价值、目标估值或完整盈利预测，交给 `a-stock-investment-analysis`。

### serenity-skill

它拥有：无特定隔夜锚点的产业链/供应链瓶颈扫描、未知卡点发现、AI/半导体价值链长期候选排序和Thesis压力测试。

本 Skill 只处理由最新隔夜事件触发的映射。若用户问“AI产业链最值得研究的卡点”而未指定昨夜事件，交给 `serenity-skill`。

## 其他不触发情形

- 普通美股新闻摘要或翻译。
- 纯美股/A股行情、技术指标查询。
- A股盘后复盘或持仓处理。
- 自动交易、自动下单、无条件荐股。
- 只要求核验一条A股消息且没有海外映射主链。
- 只要求完整公司研究、估值或盈利预测。

## 交接输出

复合请求需要交接时，输出一个简短的 `handoff_packet`：

```text
海外锚点：
数据截止：
已确认催化与等级：
A股候选及L/E/P/Evidence：
未解决问题：
需要近邻Skill继续完成的任务：
```

不得在交接包中把 `Unknown`、假设或未归因信号升级为事实。
